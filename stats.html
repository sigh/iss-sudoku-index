Solver cost by constraint type

How many guesses solved puzzles containing each type needed, for types with a sample (n) of at least 10. Each row is that type's distribution: the box spans p25–p75, the line p10–p90, and the tick marks the median. Unsolved and partial encodings are left out because their counts aren't comparable. Too‑slow % is the share of the type's searched puzzles that exceeded the evaluation cap; those runs have no guess count, so the heaviest types read as underestimates.

Parametrized tags (NFA: …, Pair: …) are grouped by their base class; grid-size and value-range tags are omitted. Types co-occur within puzzles, so per-type cost is a screening view, not attribution.
